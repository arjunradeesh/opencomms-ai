# AI for PR & Communications

An open-source collection of AI prompts, workflows, and resources designed for PR professionals, communicators, marketers, journalists, and content creators.

## Why this exists

AI is rapidly changing the communications industry, but most prompt resources are designed for developers and general productivity.

This project aims to create practical AI resources specifically for:

- Public Relations professionals
- Communications teams
- Marketing specialists
- Journalists
- Content creators
- Students entering the communications industry

## What's inside

### Media Relations
- Media pitch creation
- Journalist outreach
- Follow-up emails
- Story angle development

### Press Releases
- Announcement writing
- Product launches
- Executive statements

### Crisis Communications
- Response frameworks
- Holding statements
- Stakeholder messaging

### Content Creation
- Podcast planning
- Social media content
- Thought leadership

## How to use

Each prompt includes:

- Purpose
- When to use it
- Required inputs
- The prompt template
- Example outputs
