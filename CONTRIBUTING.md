# Contributing to OpenComms-AI

Thank you for your interest in contributing to OpenComms-AI.

This project aims to build an open-source AI toolkit for PR professionals, communicators, marketers, journalists, and content creators.

## Ways to contribute

You can contribute by:

- Adding new AI prompts
- Improving existing prompts
- Creating new communication workflows
- Sharing real-world use cases
- Suggesting new categories
- Improving documentation

## Adding a new prompt

When adding a new prompt, please include:

### Purpose

Explain what the prompt helps users achieve.

### When to use

Describe the situations where the prompt is useful.

### Required inputs

List the information users need to provide.

### Prompt template

Provide a clear and reusable AI prompt.

### Usage guidance

Explain how communications professionals can adapt the prompt.

## Quality guidelines

Contributions should be:

- Practical and relevant to communications professionals
- Clearly written
- Easy to understand
- Adaptable across industries
- Focused on responsible AI usage

## Code of conduct

Please contribute respectfully and help maintain a collaborative environment.
